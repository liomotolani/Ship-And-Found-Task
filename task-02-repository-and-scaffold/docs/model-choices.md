# Model choices

| Job                    | Tool / model   | Why this one                       |
|------------------------|----------------|------------------------------------|
| Scaffold               | Antigravity    | Plans and reads before acting      |
| Create a hero section and a card section for the home page         | Opencode - Deepseek      | To keep my token for Antigravity, since it's expensive                              |


## What I noticed about the difference
Antigravity took several minutes reading files and produced a plan before touching anything. Opencode - Deepseek started writing code almost
immediately, which was faster for a simple hero section and card section.

## One time I chose wrong and switched
So far I haven't needed to switch.
